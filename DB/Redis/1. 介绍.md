## NoSQL

- 键值对数据库（Redis）
	- 没有约束，表
- 一般value
	- jason的字符串
	- List，集合


- Redis，MongoDB，elasticsearch
	- 语法风格：简单命令、函数、像请求
	- 存储风格：键值型、文档类型、


- 与关系型数据库对比
	- ![Pasted image 20260322210225](images/Pasted%20image%2020260322210225.png)
	- 非关系型数据库设计之处就考虑数据拆分的需求
		- 根据哈希值将数据分配到不同节点上（分库）
		- 在分布式方面更好
	- 如何选择
		- 关系型：数据结构固定，对一致性、安全性高
		- 非关系型：对性能要求高


## Redis

- 特点
	- 键值型
	- 单线程（核心部分），每个命令具备原子性
	- 低延迟、速度快（基于*内存*、IO多路复用、C语言编码）
		- IO多路复用：提高吞吐能力
	- 支持数据持久化
		- 定期将数据从内存持久化到磁盘
	- 支持主从集群、分片集群
		- 主从集群：从节点可以备份主节点数据
		- 分片集群：将数据分配到不同节点上存储，提高存储上限
	- 支持多语言客户端




- ![Pasted image 20260322231023](images/Pasted%20image%2020260322231023.png)
- redis-cli：是redis提供的命令行客户端
- redis-server：是redis的服务端启动脚本
- redis-sentinel：是redis的哨兵启动脚本



## Redis启动方式

### 默认启动方式
安装完成后，在任意目录输入redis-server命令即可启动Redis：`redis-server`
如图：
![Pasted image 20260322231339](images/Pasted%20image%2020260322231339.png)

这种启动属于`前台启动`，会阻塞整个会话窗口，窗口关闭或者按下`CTRL + C`则Redis停止。不推荐使用。



### 指定配置启动
- 修改配置文件，redis.conf
	- 解压的redis安装包下（`/usr/local/src/redis-6.2.6`），名字叫redis.conf


1. 先将这个配置文件备份一份：`cp redis.conf redis.conf.bck`
2. 修改redis.conf文件中的一些配置：
```yaml
# 允许访问的地址，默认是127.0.0.1，会导致只能在本地访问。修改为0.0.0.0则可以在任意IP访问，生产环境不要设置为0.0.0.0  
bind 0.0.0.0  
# 守护进程，修改为yes后即可后台运行  
daemonize yes   
# 密码，设置后访问Redis必须输入密码  
requirepass 123321
```

- Redis的其它常见配置：
```yaml
# 监听的端口  
port 6379  
# 工作目录，默认是当前目录，也就是运行redis-server时的命令，日志.持久化等文件会保存在这个目录  
dir .  
# 数据库数量，设置为1，代表只使用1个库，默认有16个库，编号0~15  
databases 1  
# 设置redis能够使用的最大内存  
maxmemory 512mb  
# 日志文件，默认为空，不记录日志，可以指定日志文件名  
logfile "redis.log"
```

- 启动Redis：
```yaml
# 进入redis安装目录   
cd /usr/local/src/redis-6.2.6  
# 启动  
redis-server redis.conf
```

- 停止服务：
```yaml
# 利用redis-cli来执行 shutdown 命令，即可停止 Redis 服务， 
# 因为之前配置了密码，因此需要通过 -u 来指定密码  
redis-cli -u 123321 shutdown
```

### 开机自启

1. 新建一个系统服务文件：`vi /etc/systemd/system/redis.service`
2. 内容如下：
	```yaml
	[Unit]  
	Description=redis-server  
	After=network.target  
	​  
	[Service]  
	Type=forking  
	ExecStart=/usr/local/bin/redis-server /usr/local/src/redis-6.2.6/redis.conf  
	PrivateTmp=true  
	​  
	[Install]  
	WantedBy=multi-user.target
	```
3. 重载系统服务：`systemctl daemon-reload`
4. 现在，我们可以用下面这组命令来操作redis了：
	```yaml
	# 启动  
	systemctl start redis  
	# 停止  
	systemctl stop redis  
	# 重启  
	systemctl restart redis  
	# 查看状态  
	systemctl status redis
	```
5. 执行下面的命令，可以让redis开机自启：`systemctl enable redis`
