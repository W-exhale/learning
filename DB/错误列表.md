##  1. You can't specify target table 'Person' for update in FROM clause
不能在From子句中指定要更新的目标表'Person'

![Pasted image 20241114103452](images/Pasted%20image%2020241114103452.png)

- 错误代码
```sql
delete from Person
where id not in(
    select min(id) from Person group by email
)
```

也就是说不能在Person表里select，再更新Person表，需要创造一个新表select
- 正确代码
```sql
delete from Person where id not in (
    select a.id from (
        select min(id) as id from Person group by email ) a
)
```

- 也可以用左连接或者右连接的方式创两个表，留下符合要求的表，删掉不符合要求的表

## 2. status = 'cancelled_by_client' or 'cancelled_by_driver'
- 不能使用这种方式进行筛选
- 应当使用in，`status IN ('cancelled_by_client', 'cancelled_by_driver')`
