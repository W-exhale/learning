## Part 3 Flow Control Functions
### CASE()
```sql
SELECT CASE 1 WHEN 1 THEN 'one' 
[WHEN 2 THEN 'two'] 
[ELSE 'more' END]; 
->'one' 
SELECT CASE WHEN 1>0 THEN 'true' 
[ELSE 'false' END]; 
->'true' 
SELECT CASE BINARY 'B'
WHEN 'a' THEN 1 
[WHEN 'b' THEN 2]
END; 
->NULL
```
- 作用：匹配成功返回then后的内容，匹配失败返会else中的内容，没有else返回null
- 注意事项（返回值）：
	- 一个是双精度，结果为双精度
	- 没有双精度，一个是decimal，结果是decimal
	- 上面两条都无，返回整型
		- 全部是有（无）符号就有（无）符号，精度是出现的整数类型中的最高类型（tinyint,smallint,mediumint,int,bigint）
		- 如果都有，结果是有符号(signed int和unsigned int，结果是signed bigint)
		- 例外：unsigned bigint 与任何有符号整数类型组合，结果是decimal
	- 都是bit就是bit
	....
### IF()
`if(expr1,expr2,expr3)`

- 如果第一个参数ture（第一个参数!=(<>)0或者is not null），就返回参数2，否则返回参数3

### IFNULL()
`ifnull(expr1,expr2)`

- 如果参数1不为null，返回参数1，否则返回参数2

- 注意：要将返回的值存在临时表中
### NULLIF()
`nullif(expr1,expr2)`
- 如果两个参数相等，返回null，否则返回参数1

## Part 4 数字处理
- 生成随机数
`select rand();`

- 抽奖
`select * from student order by rand() limit 3;`

- 向上取整
`select ceil(3.2);`
- 四舍五入
`select round(3.1);`
也可以控制精度，`round(2.123,2)->2.12`
- 向下取整
`select floor(3.3);`

- 截取数字
`select truncte(3.1415926,2);`
输出：3.14

- 随机排序
`select * from student order by rand();`


- 转化成大写
`select ucase('abc');`

- 转化成小写
`select lcase('abc');`
