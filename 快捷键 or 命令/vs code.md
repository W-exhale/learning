
- Ctrl + F：查找
- Ctrl + H：替换

- 剪切一行：Ctrl+X
- 复制一行：Ctrl+C
- 删除一行：Ctrl+Shilft+K
- Alt+ ↑ / ↓：向上/向下移动行 Move line up/down
- Shift+Alt + ↓ / ↑：向上/向下复制行 Copy line up/down
- Ctrl + ] / \[   行缩进
- `Ctrl + L`  ：选中当前行

- Ctrl+P ：快速打开最近打开的文件
- Ctrl+Shift+N ：打开新的 window
- Ctrl+Shift+W ：关闭编辑器
- Ctrl + /  ：添加关闭行注释

- Ctrl + \`：打开集成终端
- Ctrl + Shift + \`：创建一个新的终端
