## Part 1 概述
- 在电子电路中将电信号分为模拟信号和数字信号两大类。
-模拟信号：信号幅度随时间连续变化，在时间和数值上具有连续性
-数字信号：在幅度和时间上都是离散，突变的信号

数字电路就是用于传输和处理数字信号的电子电路。（研究输出与输入信号之间的因果关系，一般称为逻辑关系）

模拟电路就是对模拟信号进行传输处理的电子电路

数字电路按电路结构可以分为：分立元件电路，集成电路
按所用期间制作工艺可以分为双极型（TTL型），单极型（MOS型）
按电路结构和工作原理可以分为时序逻辑电路和组合逻辑电路

数字电路的特点：
1. 电路结构简单，便于集成化
2. 抗干扰能力强，可靠性高（晶体管均工作在饱和区或截止区，工作在开关状态）
3. 便于长期保存和加密
4. 数字集成电路产品系列全，通用性强，成本低
5. 不仅能完成数值运算，还能进行逻辑判断。

3. **易于转换**：格雷码与二进制码之间的转换相对简单。对于一个给定的二进制数，可以通过以下公式计算其对应的格雷码：

#### 2.4 关于等式的三个重要规则
1. 代入规则
任何一个含有变量A的等式，如果将所有出现A的位置都用同一个逻辑函数代替，则等式仍然成立。这个规则称为代入规则。
2. 反演规则
对于任何一个逻辑表达式Y，如果将表达式中的所有“·”换成“＋”，“＋”换成“·”，“0”换成“1”，“1”换成“0”，*原变量换成反变量，反变量换成原变量*，那么所得到的表达式就是函数Y的反函数Y（或称补函数）。
![[Pasted image 20240921163216.png]]
3. 对偶规则
对于任何一个逻辑表达式Y，如果将表达式中的所有“·”换成“＋”，“＋”换成“·”，“0”换成“1”，“1”换成“0”，而*变量保持不变*，则可得到的一个新的函数表达式Y＇，Y＇称为函数Y的对偶函数。

- 注意
1. 先算括号，然后与运算“·”，然后或运算“+”，最后非运算。

## Part 3 逻辑函数的化简方法
### Section 1 逻辑函数的标准与或式和最简式

- 术语
-乘积项：$\overline ABC$，等等
-最小项：对n个变量，P式一个含有n个因子的乘积项，而且每一个变量都以原变量或者反变量的形式作为一个因子在P中出现且仅出现一次。
-标准与或表达式：在表达式中，每一个乘积项都是最小项

- 最小项的性质
1. 任意两个不同最小项之积为0
2. 全部最小项之和为1
3. n个变量有$2^n$次方个最小项

- 任何逻辑函数都可以表示为最小项之和的形式——标准与或表达式，一个逻辑函数只有一个最小项之和的表达式
- 标准与或表达式可以通过真值表直接看出来，1表示原变量，0表示非变量

- 最小项编号
原变量表示1，非变量表示0，写出对应的二进制数，再转化为十进制数就是对应的编号。

- 逻辑函数的最简表达式：最简与或式，最简与非-与非式，最简或与式，最简或非-或非式，最简与或非式
1. *最简与或式：乘积项的个数最少，每个乘积项中相乘的变量个数也最少*
2. 最简与非-与非式：非号个数最少，每个非号下面相乘的变量个数也最少
3. 最简或与式：括号个数最少，每个括号中相加的变量的个数也最少
4. 最简或非-或非式：非号个数最少，每个非号下面相加的变量个数也最少
5. 最简与或非式：非号下面相加的乘积项的个数最少，每个乘积项中相乘的变量个数也最少
-只要得到了函数的最简与或式，再用德摩根定理进行适当的变换，就可以得到其他的

### Section 2 逻辑函数的公式化简法
就是求出最简与或式
1. 并项：$AB+A\overline B = A$
2. 吸收：$A+AB = A$
3. 消去：$A+\overline AB=A+B$
4. 配项消项：$AB+\overline AC+BC=AB+\overline AC$，加上冗余项以消去更多的乘积项

3. 变量卡诺图的特点
- 几何相邻：1. 相接：紧挨着 2. 相对：任一行或一列的两头 3. 相重：对折起来后位置重合

- 缺点：当变量多于六个时，不适用

4. 合并规律
- 凡是几何相邻的最小项均可合并。
- 一般来说，$2^n$个最小项合并时可以消去n个变量（$2^n$个最小项说明有n个变量，当这n个变量的所有最小项都在的时候就可以将这n个变量全部消掉）

#### 3.3 具有约束的逻辑函数化简
1. 什么是约束项，约束条件？
- 分析实际问题时会发现不是所有情况都会发生，这时候就会出现约束项。
例如A校的月饼券只会发给A校的同学，那么就不会出现A校的月饼券发给B校的同学的情况，但是会出现A校月饼券不会发给B校同学的情况
-A校月饼券发给B校同学的情况所对应的就是约束项

约束项对应的是不会出现的变量取值，所以其值总等于0

由约束项加起来所构成的值为0的逻辑表达式，称为约束条件，约束条件在真值表中用（x）表示

| A(是否是A校学生) | B（是否有月饼券） | Y(是否有A校月饼) | 说明   |
| ---------- | --------- | ---------- | ---- |
| 非          | 非         | 非          |      |
| 非          | 是         |            | 不会出现 |
| 是          | 是         | 是          |      |
| 是          | 否         | 非          |      |

| A(是否是A校学生) | B（是否有月饼券） | Y(是否有A校月饼) | 说明   |
| ---------- | --------- | ---------- | ---- |
| 0          | 0         | 0          |      |
| 0          | 1         | 1          | 不会出现 |
| 1          | 1         | 1          |      |
| 1          | 0         | 0          |      |
所以上面情况中的约束项就是$\overline AB$，约束条件可以表示为$\overline AB = 0$
如果有多个约束项，就是相加等于0

2. 如何化简
在卡诺图中的约束项可以当作1进行合并（因为其值等于0所以加上最后的结果也不会有改变，圈完所有1就行约束项可以不用全圈  ），合并方法同前面
