## 二进制求和
![Pasted image 20240723154025](images/Pasted%20image%2020240723154025.png)

1. 最容易想到的：
	从后往前算，但是要注意如果需要进位，在前面增加一位数是非常困难的，所以这时候我们需要使用倒置的方式，就是将a和b倒转过来计算，翻转后的a和b从前往后加并且赋值给sum，在需要的地方赋值`\0`即可，所以使用malloc分配内存的时候，需要比更长的长度+2。

```C
void reserve(char* s) {
    int len = strlen(s);
    for (int i = 0; i < len / 2; i++) {
        char t = s[i];
        s[i] = s[len - i - 1], s[len - i - 1] = t;
    }
}

char* addBinary(char* a, char* b) {
    reserve(a);
    reserve(b);

    int len_a = strlen(a), len_b = strlen(b);
    int n = fmax(len_a, len_b), carry = 0, len = 0;
    char* ans = (char*)malloc(sizeof(char) * (n + 2));
    for (int i = 0; i < n; ++i) {
        carry += i < len_a ? (a[i] == '1') : 0;
        carry += i < len_b ? (b[i] == '1') : 0;
        ans[len++] = carry % 2 + '0';
        carry /= 2;
    }

    if (carry) {
        ans[len++] = '1';
    }
    ans[len] = '\0';
    reserve(ans);

    return ans;
}
```

**复杂度分析**
假设 $n=max\{∣a∣,∣b∣\}$。
- 时间复杂度：$O(n)$，这里的时间复杂度来源于顺序遍历 a 和 b。
- 空间复杂度：$O(1)$，除去答案所占用的空间，这里使用了常数个临时变量。
