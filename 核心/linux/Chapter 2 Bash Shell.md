## Part 2 目录操作
### `ls` 命令：列出目录内容
#### 普通ls
- `ls`：当前目录所有文件和文件夹（默认不包括隐藏文件）
*   `ls -a`: 列出所有文件和文件夹，**包括**隐藏文件 (`all`)。
* `ls -l`: 以**长格式** (`long`) 显示文件详细信息，包括权限、所有者、大小、修改日期等。
- `ll`：显示文件形式，所属用户，日期时间等等，显示当前目录所有文件的属性，作用和`ls -l -a`(`ls -al`)一样
*   `ll`: 显示文件形式，所属用户，日期时间等等，显示当前目录所有文件的属性通常是 `ls -alF` 或 `ls -l --color=auto` 等命令的**别名** (`alias`)。
	![[Pasted image 20241121204857.png]]
	![[Pasted image 20241121204921.png]]
*   `man ls`: 查看 `ls` 命令的**手册页** (`manual`)，获取详细用法说明。按 `q` 退出手册页。
	![[Pasted image 20241121202932.png]]

- `ls -m`：文件名之间用逗号隔开
	![[Pasted image 20241121205400.png]]
* `ls -F`: 在目录名后附加 `/`，可执行文件后附加 `*`，符号链接后附加 `@` 等，以区分文件类型。
* `ls -R`: **递归** (`Recursive`) 列出所有子目录的内容。
- `ls -FR`：遍历所有目录
- `ls Documents/ -FR`：遍历Documents中的所有文件

#### ls过滤
* `*`: 匹配**零个或多个**任意字符。
	*  `ls -l fhs-2.3_*.pdf` 会列出所有以 `fhs-2.3_` 开头且以 `.pdf` 结尾的文件，如 `fhs-2.3_copy_1.pdf`, `fhs-2.3_copy_2.pdf`, `fhs-2.3.pdf` 
* `?`: 匹配**一个**任意字符。
	* `ls file?.txt` 会列出 `file1.txt`, `fileA.txt` 但不会列出 `file10.txt`。
* `[...]`: 匹配方括号中**任意一个**字符。可以使用范围 (`a-z`, `0-9`)。
	*  `ls -l f[a-x]ck.txt` 会列出 `fack.txt`, `fbck.txt`, ..., `fxck.txt`。
* `[!...]` 或 `[^...]`: 匹配**不在**方括号中的任意一个字符 (取反)。
### `cd` 命令：切换目录

- cd到home目录的方式：
	- `cd /home/w-exhale`（绝对路径）
	- `cd ~`
	- `cd`（不带参数）
- 回到上一层目录：`cd ..`
- 返回上两级目录：`cd ../..`
- 回到上次操作的目录：`cd -`

### 其他相关命令
- 输出绝对路径：`pwd`
*   `gedit <文件路径>`: 使用 `gedit` 文本编辑器打开文件 (需要图形界面环境)。
*   **单点符 `.`**: 代表**当前**目录。
*   **双点符 `..`**: 代表当前目录的**父目录**。
*   **组合命令 `&&`**: 用于连接两个命令，只有**前一个命令成功执行** (返回值为 0)，后一个命令才会执行。
	- `cd ../doc && ls -alF`（回到上一级文件夹的doc文件夹并且展开doc文件夹）
- 强制退出：`Ctrl+C`
- 复制：右击点copy，或者`Ctrl+Shift+C`，`Common+C`
- 撤销：没有撤销这个概念
## Part 3 Linux 文件系统结构

### Windows vs. Linux 路径

*   **Windows**: 使用**反斜杠 `\`** 作为路径分隔符，有**盘符** (如 `C:`, `D:`) 作为文件系统的起点。
    *   示例: `D:\software\Obsidian`
*   **Linux**: 使用**正斜杠 `/`** 作为路径分隔符，**没有盘符**概念。所有文件和目录都在一个**单一的根目录 `/`** 下。
    *   `~`：表示当前用户的**主目录** ( `/home/w-exhale`)。
    *   示例: `/home/user/Documents/1.txt`
![[Pasted image 20241121211025.png]]![[Pasted image 20241121211208.png]]

>[!WARNING] 注意
Linux 没有 C 盘、D 盘等概念。安装软件时通常不需要像 Windows 那样选择安装目录，系统会根据 FHS 标准将其放置在合适的默认位置。

### 主要目录说明 (FHS 标准)
- Linux 文件系统遵循 **FHS (Filesystem Hierarchy Standard)**，规定了主要目录的用途。】

- 根目录下面的文件解释
home相当于windows里的用户
-   `/`: linux根目录
*   `/bin`: **二进制目录**，包含系统启动和运行所需的基本命令， GNU工具（系统自带的命令也在里面，比如说里面有一个文件叫ls就是ls命令的文件）
*   `/sbin`: **系统二进制命令** (`System Binary`)，包含系统管理所需的命令 (如 `fdisk`, `ifconfig`, `reboot`)，主要供 root 用户使用。（系统二进制目录，GNU高级管理员使用的命令工具）
*   `/etc`: **系统配置文件** (`Etcetera`)，包含系统和应用程序的配置文件。类似 Windows 的注册表或 `C:\Windows` 中的文件。
*   `/home`: **用户主目录**，每个普通用户在此目录下有一个自己的子目录 (如 `/home/w-exhale`)。相当于 Windows 里的 `C:\Users`。
*   `/root`: **root 用户** (超级管理员) 的主目录。
*   `/lib`, `/lib64`: **共享库** (`Libraries`)，存放 `/bin` 和 `/sbin` 中程序所需的最基本的动态连接共享库文件。（库目录 存放系统应用程序，安装软件A可能需要增添B软件依赖，需要一些库）
*   `/usr`: **用户程序** (`Unix System Resources`)，包含绝大多数用户安装的应用程序、库、文档等。这是系统中最大的目录之一。（普通用户使用的GNU工具）
    *   `/usr/bin`: 用户安装的应用程序命令 (如 `java`, `python`)。
    *   `/usr/sbin`: 用户安装的系统管理命令。
    *   `/usr/lib`: 用户安装的应用程序库。
    *   `/usr/local`: 本地安装的软件目录，通常用于管理员手动编译安装的软件，以区别于系统包管理器安装的软件。
    *   `/usr/share`: 体系结构无关的共享数据，如文档、图标等。
*   `/var`: **可变目录** (`Variable`)，存放经常变化的文件，如日志 (`/var/log`)、邮件队列、打印池、Web 服务器数据等。
*   `/tmp`: **临时目录** (`Temporary`)，存放临时文件，系统重启后内容通常会清空。相当于windows上的磁盘清理里面清理的临时文件。
*   `/boot`: **启动目录**，包含 Linux 内核和引导加载程序 (如 GRUB) 所需的文件。
*   `/dev`: **设备文件** (`Device`)，包含代表硬件设备的文件节点 (如硬盘 `/dev/sda`, 终端 `/dev/tty1`)。类似 Windows 里的设备管理器。
*   `/proc`: **进程信息** (`Process`)，一个**虚拟文件系统**，实时反映内核和进程状态信息 (内容在内存中，不占硬盘空间)。
*   `/sys`: **系统信息** (`System`)，一个**虚拟文件系统**，提供设备、驱动程序和内核特性的接口。
*   `/mnt`: **临时挂载点** (`Mount`)，用于临时手动挂载文件系统 (如 U 盘、网络共享)。
*   `/media`: **可移动媒体挂载点**，用于系统自动挂载可移动设备 (如 U 盘、光盘、MP3 播放器)。（媒体目录，可移动设备的挂载点有的mp3等插在电脑上可以自动播放可能就在media里）
*   `/opt`: **可选应用程序** (`Optional`)，用于存放第三方软件包，不是linux自己的软件，通常是大型、
*   `/srv`: **服务数据** (`Service`)，存放本地服务提供的数据 (如 Web 服务器的网站文件)。（相当于windows中的服务）
*   `/lost+found`: 在 ext 文件系统中，用于存放文件系统检查 (`fsck`) 过程中恢复的孤立文件块。（突然断电了的临时文件）
*   `/run`: **运行时变量数据**，存放系统自启动以来产生的运行时数据，如 PID 文件、socket 文件。（打开一个软件进行使用，就会在这个目录里创建一个文件夹）
*   `/cdrom`: 传统的光盘挂载点 (现在多用 `/media`)。
*   `/snap`: Ubuntu 特有的目录，用于存放 Snap 软件包。

> [!NOTE] FHS 标准
> 了解 FHS 有助于理解 Linux 系统的组织方式。详细标准可查阅：[Filesystem Hierarchy Standard](https://www.pathname.com/fhs/)
> 看懂了这个就知道linux目录里面的文件是干嘛的了

## Part 5 与文件有关的命令
### `touch`: 创建空文件或更新时间戳
*   `touch 文件名`:
	- 创建空txt文件：`touch 2.txt`
	- 如果这个文件已经存在：使用`touch`就会将这个文件的时间标签更新为系统当前时间（之前的数据还在）
### `cp`: 复制文件或目录
*   `cp 源文件 目标文件`: 复制文件。
    ```bash
    cp 1.txt 2.txt
    ```
    *   如果 `目标文件` 不存在，会自动创建。
    *   如果 `目标文件` 已存在，**默认会覆盖**其内容 (这可能导致数据丢失，不太好)。

-   `cp -i 1.txt 2.txt`：覆盖既有文件前询问用户(回答y或n)
覆盖后的时间标签会更新
*   `cp 源文件 目标目录/`: 将源文件复制到目标目录下，保持原文件名。
    ```bash
    cp -i 1.txt /home/frank/Downloads/
    cp -i 1.txt ~/Downloads/  # 使用 ~ 代表主目录
    cp -i 1.txt ../           # 复制到上级目录
    cp -i ../pdf/* .          # 将上级目录 pdf 下所有文件复制到当前目录 .

```

*   `cp -r 源目录 目标目录/`: **递归** (`recursive`) 复制整个目录及其所有内容。复制目录**必须**使用 `-r` 或 `-R` 选项。
```bash
    # 正确方式：递归复制整个目录
    cp -r /home/frank/Documents/doc/ /home/frank/Downloads/
    cp -r ~/Music/Jack/ ~/Documents/doc/
```
- 将一个文件复制到另一个文件夹里
`cp -i 1.txt /home/frank/Downloads/`
或者`cp -i ~/Downloads/`（相对路径）

> [!WARNING] 覆盖风险
> 使用 `cp` 时，如果不加 `-i` 选项，可能会无意中覆盖重要文件。建议养成使用 `-i` 的习惯或在 `.bashrc` 中配置别名 `alias cp='cp -i'`。

### `mv`: 移动或重命名文件/目录
*   **移动**: `mv 源路径 目标目录/`
    ```bash
    mv ./1.txt ./file1/  # 将当前目录的 1.txt 移动到 file1 目录下
    ```
    *   移动目录和移动文件语法相同，**不需要**像 `cp` 那样加 `-r`。
*   **重命名**: `mv 旧名称 新名称` (在同一目录下移动即为重命名)
    ```bash
    mv 1.txt 2.txt  # 将 1.txt 重命名为 2.txt
    ```
*   `mv -i 旧名称 新名称`: 交互式移动/重命名，在覆盖前询问。
#### `!$` 技巧

`!$` 代表**上一条命令的最后一个参数**。
![[Pasted image 20250208171655.png]]
在图中，执行 `mv 1.txt ./file1/` 后，`!$` 就代表 `./file1/`。所以 `cd !$` 就相当于 `cd ./file1/`，可以快速进入刚才操作的目标目录。

### `rm`: 删除文件或目录
- 删除（remove）：linux用这个命令是直接删除而不是移入回收站
*   `rm 文件名`: 删除文件。
*   `rm -i 文件名`: **交互式**删除，删除前询问确认。**强烈推荐**！
*   `rm -r 目录名`: **递归**删除目录及其所有内容 (包括子目录和文件)。删除非空目录必须用 `-r`。
*   `rm -f 文件或目录`: **强制** (`force`) 删除，不进行提示，即使文件是只读的。**谨慎使用**！
*   `rm -ir 目录名` 或 `rm -i -r 目录名`: 交互式递归删除，删除每个文件和进入每个子目录前都会询问。相对安全的方式删除目录。

> [!DANGER] 极度危险的命令
> *   `rm` 命令删除的文件**通常无法恢复** (不像 Windows 回收站)。
> *   **绝对不要**以 root 权限执行 `sudo rm -rf /*` 或类似命令，这会删除整个系统！
> *   删除文件或目录时，**强烈建议始终使用 `-i` 选项**进行确认。
> *   **极度谨慎使用 `-f` 选项**，只在完全确定后果时使用。
> *   删除空目录可以用 `rmdir`，但 `rm -r` 更通用。

### `mkdir`: 创建目录
- 创建目录：mkdir（make direction）
*   `mkdir 目录名`: 创建一个新目录 (`make directory`)。
    ```bash
    mkdir my_project
    ```
*   `mkdir -p 路径/到/新目录`: **递归创建**目录 (`parents`)，如果路径中的父目录不存在，也会一并创建。
    ```bash
    mkdir -p js/src/util  # 会依次创建 js, js/src, js/src/util
    ```

### `ln`: 创建链接文件
- Windows中的快捷方式的文件扩展名是.lnk（链接文件，link file）
- Linux中的链接文件有两种
	- 符号链接(Sysmbolic links)（软连接 soft links）：快捷方式样的
		- 存储的是指向**目标文件或目录的路径**。
	    *   可以跨文件系统创建。
	    *   可以为目录创建链接。
	    *   可以为不存在的文件创建链接 (此时链接无效，称为"断链")。
	    *   删除源文件，符号链接失效。
	- 硬链接：创建一个虚拟的文件，（类似windows中的副本，但不完全一样）
		- 相当于给文件创建了一个**额外的文件名入口**，指向同一个**物理存储数据块 (inode)**。
	    *   源文件必须存在才能创建。
	    *   删除源文件或任意一个硬链接，只要还有其他链接指向该 inode，文件内容**仍然存在**。只有当所有指向 inode 的链接都被删除后，数据才会被标记为可覆盖。
	- 注意这两种方式，它们原来的文件都必须存在

- 创建符号链接： `ln -s 目标路径 链接名称`
	```bash
	ln -s 1.java 1_softlink
	```
	![[Pasted image 20250205220943.png]]
	(可以看到图中 `l` 开头表示符号链接，且指向 `1.java`，大小通常是路径字符串的长度)

- 创建硬链接： `ln 目标文件 链接名称` (没有 `-s`)
	```bash
	ln 1.java 2_hardlink
	```
	![[Pasted image 20250205221511.png]]
	(图中 `ls -l` 显示链接数 `2`（第二列），表示有两个文件名指向同一个 inode，链接文件类型是普通文件 `-`，大小和源文件相同)


> [!NOTE] 使用场景
> *   **软链接**更常用，更灵活，类似快捷方式。
> *   **硬链接**主要用于文件备份或防止重要文件被误删 (只要还有一个硬链接在，文件就在)。只能在同一个文件系统中才能创建（同一个盘）

## 命令行编辑与历史

### 光标移动与编辑快捷键
*   `Tab`: **命令或路径自动补全**。按一次尝试补全，按两次列出所有可能选项。极大提高效率并减少输入错误。（手动写容易写错，不存在的文件会自动创建）
*   `Ctrl+A`: 光标移动到命令行的**开头**。
*   `Ctrl+E`: 光标移动到命令行的**结尾**。
*   `Ctrl+B` 或 `←` (左箭头): 光标向**左**移动一个字符。
*   `Ctrl+F` 或 `→` (右箭头): 光标向**右**移动一个字符。
*   `Ctrl+L`: **清屏** (相当于执行 `clear` 命令)。
*   `Ctrl+H` 或 `Backspace`: 删除光标**前**的一个字符。
*   `Ctrl+T`: 如果在命令行结尾**交换**光标前两个字符的位置，在中间就交换方块内和它前面的数。
- Ctrl+方向键：按单词移动（按下划线）
*   `Ctrl+U`: 删除从光标位置到命令行**开头**的所有内容。
*   `Ctrl+K`: 删除从光标位置到命令行**结尾**的所有内容。
*   `Ctrl+W`: 删除光标**前**的一个**单词**。
- Ctrl+R：之前用过的命令

### 命令历史
*   `↑` (上箭头) / `Ctrl+P`: 显示**上一条**历史命令。
*   `↓` (下箭头) / `Ctrl+N`: 显示**下一条**历史命令。
*   `Ctrl+R`: **反向搜索**历史命令。输入关键字，Shell 会显示最近一条包含该关键字的命令，继续按 `Ctrl+R` 查找更早的匹配项。找到后按 `Enter` 执行，或按左右箭头进行编辑。
* *   `history`: 显示所有历史命令列表 (带编号)。
*   `!编号`: 执行历史记录中指定编号的命令 (如 `!100`)。
*   `!!`: 执行**上一条**命令。
*   `!字符串`: 执行最近一条以 `字符串` 开头的命令 (如 `!ls`)。

## 文件内容查看与类型探测

### `file`: 探测文件类型
*   `file 文件名`: 分析文件内容，判断并显示文件类型 (如文本、图像、可执行文件、目录等)。
    ```bash
    file one.txt
    file /bin/ls
    file .
    ```
    ![[Pasted image 20250209212000.png]]
### `cat`: 查看文件全部内容 (适合小文件)
*   `cat 文件名`: 将文件的全部内容**一次性**输出到终端 (`Concatenate`)。适合查看内容较少的文本文件。
*   `cat -n 文件名`: 显示内容并**加上行号**。
*   `cat -A` 或 `cat -vET`: 显示所有内容，包括**非打印字符** (如 Tab 显示为 `^I`, 换行符显示为 `$`, 其他控制字符用 `^` 表示)。

### `less`: 分页查看文件内容 (推荐)
*   `less 文件名`: 以**分页**方式查看文件内容，功能比 `more` 更强大，支持前后翻页和搜索。是查看大文件的常用工具。
    *   **常用操作**:
        *   空格键 / `PageDown` / `f`: 向下翻一页。
        *   `b` / `PageUp`: 向上翻一页。
        *   `d`: 向下翻半页。
        *   `u`: 向上翻半页。
        *   `Enter` / `j`: 向下滚动一行。
        *   `k`: 向上滚动一行。
        *   `/关键字`: 向下搜索关键字 (按 `n` 查找下一个, `N` 查找上一个)。
        *   `?关键字`: 向上搜索关键字 (按 `n` 查找下一个, `N` 查找上一个)。
        *   `g`: 跳转到文件开头。
        *   `G`: 跳转到文件末尾。
        *   `q`: 退出 `less`。
### `more`: 分页查看文件内容 (基本)
*   `more 文件名`: 也是分页显示，但功能比 `less` 少 (例如默认不能向上翻页)。
    *   **常用操作**:
        *   空格键: 向下翻一页。
        *   `Enter`: 向下翻一行。
        *   `q`: 退出 `more`。

### `head`: 查看文件开头部分
*   `head 文件名`: 默认显示文件的前 **10** 行。
*   `head -n 行数 文件名`: 显示文件的前 `行数` 行。
    ```bash
    head -n 2 demo.c  # 显示 demo.c 的前 2 行
    ```

### `tail`: 查看文件结尾部分 (常用于日志)

*   `tail 文件名`: 默认显示文件的最后 **10** 行。
*   `tail -n 行数 文件名`: 显示文件的最后 `行数` 行。
    ```bash
    tail -n 2 demo.c  # 显示 demo.c 的最后 2 行
    ```
*   `tail -f 文件名`: **实时**跟踪文件末尾的新增内容 (`follow`)，常用于查看动态更新的日志文件。按 `Ctrl+C` 停止跟踪。
> [!NOTE] 适用性
> `cat`, `less`, `more`, `head`, `tail` 主要用于查看**文本文件**。对于二进制文件 (如音乐、图片、编译后的程序)，直接使用这些命令查看会显示乱码。
