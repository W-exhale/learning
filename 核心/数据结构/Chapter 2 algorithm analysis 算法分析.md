## 数学基础
### 一些数学定义

1. 如果存在正常数c和$n_0$ 使得当$N\geqslant n_0$ 时 $T(N)\leqslant cf(N)$ ，则记为 $T(N)=O(f(N))$

最后总会存在某个点$n_0$ ，从它之后，$c·f(N)$总是至少与T(N)一样大，如果忽略常数，则是f(N)至少与T(N)一样大。例如，假设T(N) = 1000N, f(N) = $N^2$ ，$n_0$ = 1000而c = 1。也可以使$n_0$ = 10 或100。于是可以说1000N = O($N^2$)(N平方级)。这种记法称为大O记法。
（c在这里感觉是起一个严谨性的作用，加上并不会改变最终的趋势）

2. 如果存在正常数c和$n_0$ 使得当$N\geqslant n_0$ 时 $T(N)\geqslant cg(N)$ ，则记为 $T(N)=\Omega(g(N))$ 

3. $T(N) = \Theta(h(N))$ 当且仅当$T(N) = O(h(N))$ 且$T(N) = \Omega(h(N))$ 

4. 如果  $T(N) = O(p(N))$  且$T(N) \neq \Theta(h(N))$ 则 $T(N) = o(p(N))$ 
（加了O保护的增长率大于等于，$\Omega$小于等于，$\Theta$相等，o大于）
比较相对增长率，如果用传统的不等式来计算增长率。
第一个定义：T（N）的增长率小于等于f(N)的增长率
第二个定义：$T(N)=\Omega(g(N))$是说T（N）的增长率大于等于g(N)的增长率
第三个定义： $T(N) = \Theta(h(N))$是说T（N）的增长率等于$\Theta$(h(N))的增长率
第四个定义： $T(N) = o(p(N))$ 是说T（N）的增长率小于p(N)的增长率

## 运行时间计算

为简化分析，一些要求：
- 不存在特定的时间单位
- 计算大O运行时间，大O是一个上界，（不能低估程序的运行时间）
- 程序可能提前结束，但绝不可能拖后

### 一般法则

中心：从内部（或最深层的部分）向外展开，如果有调用，这些调用要首先分析。
如果是递归，分情况；如果它实际上是for循环，其分析较为简单,如下面的函数运行时间为O(N)
```C
Factorial( int N )
{
	if(N <= 1)
	return 1;
	else
	return N * Factorial(N - 1)
	}
```
#### 法则一：for循环
至多是该for循环内语句（包括测试）的运行时间x迭代的次数。
#### 法则二：嵌套的for循环
从里向外分析。一组嵌套循环的内部的一条语句总的运行时间为该语句的运行时间x该组所有的for循环的大小的乘积。
```C
for(i = 0; i < N; i++)
	for(j = 0; j < N; j++)
		k++;
```

上面程序代码片段为$O(N^2)$

#### 法则三：顺序语句
将各个语句的运行时间求和即可（其中的最大值就是所得的运行时间；见[[Chapter 2 algorithm analysis 算法分析#重要结论|法则1（a）]]）
```
for(i = 0; i < N; i++)
	num = i;
for(i = 0; i < N; i++)
	for(j = 0; j < N; j++)
		statements = i + j;
```

上面程序片段的总开销为$O(N^2)$

#### 法则四：IF/ELSE 语句
```
if(condition)
	S1
else
	S2
```
这种类型的运行时间为S1加上S2.

##### 时间复杂度
做复杂度分析（实际上就是做CURD的分析）
一个数组arr[0, 1, 2, 3, 4, ....N - 1 ]
- 查（分析在查的时候有多快）
比做查房，比如说一开始是一个病人（arr[1]),之后有N个病人（arr[N]）
1. 查单个元素的值（ 复杂度求法）
arr[?]=>O(1)T（Time）（计算机用数组下标的形式来查快！）
2. 查N（N求和，sum(N))
有多少个人就有多少个人的时间。
例如，查N个。就是O(N)T
也叫遍历。
3. 两个数组，
一号数组第一个（1.1）对2.1
1.1对2.2，1.1对2.3。。。
1.2对2.1，1.2对2.2。。。
一共$N^2$次，O($N^2$)T
