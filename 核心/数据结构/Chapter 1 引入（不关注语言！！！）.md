#### 级数内容

##### 几何级数
                  $\sum\limits_{i=0}^N 2^i = 2^{N+1} - 1$
				
				   $\sum\limits_{i=0}^N A^i =  \frac{A^{N+1} - 1}{A - 1}$

在第二个公式中，如果0<A<1,则
        
		  $\sum\limits_{i=0}^N A^i \leq \frac{1}{1 - A}$
		  
当N趋于无穷时，该和趋于1/（1 - A）

##### 算术级数

 1.  $\huge\sum\limits_{i=0}^N i$ = $\huge\frac{N(N + 1)}{2}$ $\huge\approx$ $\huge\frac{N^2}{2}$
 
 2. $\huge\sum\limits_{i=1}^N i^2$ =  $\huge\frac{N(N + 1)(2N + 1)}{6}$ $\huge\approx$ $\huge\frac{N^3}{2}$            
 3.  $\huge\sum\limits_{i=1}^N i^k \approx  \frac{N^{k + 1}}{|k + 1|}$                    $\huge k \neq -1$
 当k = -1时，该公式不成立，需要下列公式。 

$H_N$ = $\huge\sum\limits_{i=1}^N \frac{1}{i}$ =  $\huge\frac{N(N + 1)(2N + 1)}{6}$ $\huge\approx$ $\huge log_eN$

数$H_N$叫做调和数，其和叫做调和和，上面近似式中的误差趋向于$\gamma \approx0.57721566$ ，这个值称为欧拉常数。

### 模运算

同余式：正整数a，b对p取模，它们的余数相同，记做 a ≡ b % p或者a ≡ b (mod p)。

（1）若p=a-b，则a≡b (% p)。例如 11 ≡ 4 (% 7)， 18 ≡ 4(% 7)

（2）(a % p)=(b % p)意味a≡b (% p)

（3）[对称性](https://baike.baidu.com/item/%E5%AF%B9%E7%A7%B0%E6%80%A7/0?fromModule=lemma_inlink)：a≡b (% p)等价于b≡a (% p)

（4）[传递性](https://baike.baidu.com/item/%E4%BC%A0%E9%80%92%E6%80%A7/1695468?fromModule=lemma_inlink)：若a≡b (% p)且b≡c (% p) ，则a≡c (% p)

模运算与基本[四则运算](https://baike.baidu.com/item/%E5%9B%9B%E5%88%99%E8%BF%90%E7%AE%97/5337481?fromModule=lemma_inlink)有些相似，但是除法例外。其规则如下：

(a + b) % p = (a % p + b % p) % p （1）

(a - b) % p = (a % p - b % p ) % p （2）

(a * b) % p = (a % p * b % p) % p （3）

(a^b) % p = ((a % p)^b) % p （4）

### 证明方法

#### 归纳法证明
- 有两个标准的部分
1. 证明基准情形（base case）：即确定某个或某些小的值的正确性
2. 归纳假设：假设定理对某个有限数k的所有情况都是成立的。然后用这个假设证明下一个数k+1也成立。


#### 反证法

假设定理不成立，用已知性质推翻

## 递归简论
- 注意：
1. 要使用递归一定会有基准情况：
```
int fun(int number){
	if(number  == 0)     //1
		return 0;        //2
	else
	return fun(number - 1) * number;
}
```
上面函数段的基准情况就是第一行和第二行。

2. 递归不是循环逻辑
[[函数#递归|递归]]

数值计算通常不使用递归，一般解释递归会用数值计算来解释。

3. 不断推进。不断向基准情形推进。
书中举了一个很贴切的例子，在词典中找单词，单词的示意不懂，又查新的词。

4. 设计法则
假设所有递归调用都能运行。

- 递归的基本法则
1. 基准情形
2. 不断推进
3. 设计法则
4. 合成效益法则：在求解一个问题的同意实例时切勿在不同的递归调用中做重复性的工作。
