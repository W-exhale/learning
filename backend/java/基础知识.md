## 1.Java原理介绍
### 1.1 Java 与 C 语言运行机制对比
*   **C 语言:**
    *   编译后生成特定平台的可执行文件（例如 Windows 下的 `.exe`）。
    *   可以直接双击运行（在对应操作系统上）。
*   **Java 语言:**
    *   **编写:** 创建后缀为 `.java` 的源文件。可以在文本编辑器或 IDE（如 VS Code）中创建。
    *   **编译:** 使用 `javac` 命令将 `.java` 源文件编译成后缀为 `.class` 的**字节码文件**。
        *   `.class` 文件是二进制文件，包含了平台无关的指令，不能直接运行。
    *   **运行:** 使用 `java` 命令，通过 **Java 虚拟机 (JVM)** 来解释执行 `.class` 文件。
        *   命令格式：`java ClassName` (注意：此处 `ClassName` 不带 `.class` 后缀)。
        *   **前提:** 必须先有 `.class` 文件。
    *   **直接运行 (JDK 11+):** 可以使用 `java YourSourceFile.java` 命令直接编译并运行单个 Java 源文件，无需手动生成 `.class` 文件。

- **java运行流程**
程序员编写`.java`代码->使用javac编译->生成class字节码文件-> JVM 加载并执行 `.class` 文件

### 1.2 Java 平台核心组件

*   **JVM (Java Virtual Machine):** Java 虚拟机
    *   是 Java 程序运行的基础，负责解释或编译执行 `.class` 字节码文件。
    *   内置于 JRE 和 JDK 中，通常用户不可见。
    *   **核心作用:** 实现 Java 的**跨平台性**。同一份 `.class` 文件可以在任何安装了对应 JVM 的操作系统（Windows, macOS, Linux 等）上运行。相比之下，C 编译的 `.exe` 文件通常只能在 Windows 上运行。
*   **JRE (Java Runtime Environment):** Java 运行环境
    *   包含 JVM 以及 Java 程序运行所必需的核心类库和资源。
    *   如果只需要运行 Java 程序，安装 JRE 即可。
*   **JDK (Java Development Kit):** Java 开发工具包
    *   包含 JRE 的所有内容，并额外提供了开发 Java 程序所需的工具，如编译器 (`javac`)、调试器 (`jdb`)、文档生成器 (`javadoc`) 等。
**关系:** JDK 包含 JRE，JRE 包含 JVM。

*   **分发 Java 程序:** 通常将编译好的 `.class` 文件（或打包成的 JAR 文件）分发给他人。接收方需要安装 JRE 或 JDK（因为它们都包含 JVM）,通过jvm用java命令打开。

### 1.3 Java 项目结构与包 (Package)
#### 项目结构
一个标准的 Java 项目通常包含以下主要目录：
*   `.idea`: IntelliJ IDEA IDE 的项目配置文件目录。
*   `out`: 存放编译后生成的 `.class` 文件。
*   `src`: 存放项目源代码 (`.java` 文件)。开发者的主要工作区域。

![Pasted image 20240918123856](images/Pasted%20image%2020240918123856.png)
#### 包 (Package)
*   **作用:** 组织和管理 Java 类，避免命名冲突，类似于文件系统中的文件夹。
*   **命名规范:** 通常使用反向域名，全部小写，例如 `com.company.projectname.module`。
    *   `com.company.demo`: `com` 通常代表商业组织，`company` 是公司名，`demo` 是项目或模块名。这是一种约定俗成的模式。
*   **层级关系:** 包名中的 `.` 表示目录层级。
*   **声明:** 在 `.java` 文件的 **第一行** 使用 `package` 关键字声明该文件所属的包：`package com.company.demo;`

My evaluation：可以将java的类理解尾一个包含数据（成员变量）和操作这些数据的函数的结构体，方法的调用类似C语言中的函数指针
#### 导入 (Import)
*   **作用:** 在当前文件中使用其他包中的类。
*   **关键字:** `import` (不同于 C/C++ 的 `#include`)。
*   **规则:**
    *   如果包在src文件的同一个文件夹（包）下，可以不用导包，但是如果不同则需要导包。
    *   `java.lang` 包下的类（如 `String`, `System`, `Integer` 等）是 Java 的核心基础类，会被**自动导入**，无需手动 `import`。(也就是自带的包不用导)

初级示例
```java
// 1. 包声明 说明Main.java这个文件在哪
package com.company.demo; 

// 2. 导包
import com.company.tools.Student;//导包

// 3. 类定义
public class Main {  
//public公共的，class类（理解为类别），Main就是类名  
    
    // 4. main 方法 - 程序的入口点 (固定格式)
    public static void main(String[] args) {  
        //java中一般是返回void，C中一般是int
        // String[] args: 接收命令行传入的参数
        
        int numberA = 1, numberB = 2;  
        int sum = sum(numberA, numberB);  
        System.out.println("Hello!"); 
        System.out.println("sum = " + sum);  
  
    }  
    // 5. 自定义静态方法
    public static int sum(int numberA, int numberB){  
        return numberA + numberB;  
    }  
}
```

## 2. 数据类型
Java 数据类型分为两大类：**基本数据类型 (Primitive Types)** 和 **引用数据类型 (Reference Types)**。

### 2.1 基本数据类型 (8 种)

| 类型      | 大小(位) | 描述                     | 默认值  | 示例                  |
| :-------- | :------- | :----------------------- | :------ | :-------------------- |
| `byte`    | 8        | 带符号整数 (补码)        | `0`     | `byte b = 10;`        |
| `short`   | 16       | 带符号整数               | `0`     | `short s = 200;`      |
| `int`     | 32       | 带符号整数 (默认整数类型) | `0`     | `int i = 1000;`       |
| `long`    | 64       | 带符号整数               | `0L`    | `long l = 100000L;`   |
| `float`   | 32       | 单精度浮点数             | `0.0f`  | `float f = 3.14f;`    |
| `double`  | 64       | 双精度浮点数 (默认小数类型)| `0.0d`  | `double d = 3.14159;` |
| `char`    | 16       | 单个 Unicode 字符        | `\u0000`| `char c = 'A';`       |
| `boolean` | (逻辑上1位)| 逻辑值 (真/假)           | `false` | `boolean flag = true;`|

**注意:**
*   `long` 类型常量后缀用 `L` 或 `l` (推荐 `L` 避免与数字 1 混淆)。
*   `float` 类型常量后缀必须用 `F` 或 `f`。
*   `char` 类型表示 Unicode 字符，范围 `\u0000` 到 `\uffff` (0 到 65535)，可以参与算术运算。
*   `boolean` 类型只有 `true` 和 `false` 两个值。
*   `void` 是一种特殊类型，表示无返回值，有对应的包装类 `java.lang.Void`，但不能直接操作。

### 2.2 引用数据类型
*   **概念:** 变量存储的是对象的**内存地址引用**，而非对象本身。类似于 C/C++ 的指针，但 Java 中无法直接操作内存地址。
*   **种类:** 类 (Class)、接口 (Interface)、数组 (Array)、枚举 (Enum)、注解 (Annotation)。
*   **默认值:** `null` (表示不指向任何对象)。
*   **特点:**
    *   引用类型变量在声明时指定类型，一旦声明后类型不能改变。
    *   可以指向其声明类型或其**子类型**的任何对象（多态）。
    *   对象和数组都属于引用数据类型。
*   **示例:** `String siteName = new String("Runoob");` `int[] numbers = new int[10];`

### 2.3 字符串：String类型
#### 常用方法
*   `length()`: 获取字符串长度。`int len = str1.length();`
*   `concat(String str)`: 连接字符串。`String combined = str1.concat(str2);`
	*   `+` 运算符: 更常用的字符串连接方式。`String message = "Hello" + " " + "World" + "!";`
*   `equals(Object obj)`: 比较字符串**内容**是否相等 (区分大小写)。
*   `equalsIgnoreCase(String anotherString)`: 比较字符串内容是否相等 (忽略大小写)。
*   `charAt(int index)`: 获取指定索引位置的字符。
*   `substring(int beginIndex)` / `substring(int beginIndex, int endIndex)`: 获取子字符串。
*   `indexOf(String str)` / `lastIndexOf(String str)`: 查找子字符串首次/最后一次出现的位置。
*   `toUpperCase()` / `toLowerCase()`: 转换为大写/小写。
*   `trim()`: 去除字符串首尾的空白字符。
*   `split(String regex)`: 根据指定的分隔符拆分字符串为字符串数组。
- 创建格式化字符串：`System.out.printf("A = %d", A);`

其他字符串用法：[String (Java SE 9 & JDK 9 ) (oracle.com)](https://docs.oracle.com/javase/9/docs/api/index.html?overview-summary.html)

- 字符数组转字符串：`String helloString = new String(char[]);`
```java

		char[] helloArray = {'r', 'u', 'n','o','o','b'};
```

- 关于字符串结尾“`\0`”
	*   C 语言字符串以 `\0` 作为结束符，需要显式处理。

### 2.4 类型转换
#### 2.4.1 自动类型转换 (隐式转换)
*   **规则:** `byte` -> `short` / `char` -> `int` -> `long` -> `float` -> `double`。
1. 整数的默认类型是int
2. 小数的默认类型是double
3. `byte`, `short`, `char` 参与运算时，会**首先自动提升为 `int` 类型**。

#### 2.4.2 强制类型转换 (显式转换)
1. 在把容量大的类型转换成容量小的类型时必须使用强制类型转换
2. 不能对boolean类型进行类型转换
3. 转换过程中可能导致溢出或损失精度
4. 浮点数到整数的转换是通过舍弃小数得到，而不是四舍五入
```java
    int i = 200;
    byte b = (byte) i; // 强制将 int 转换为 byte，可能溢出
    double d = 9.8;
    int num = (int) d; // 强制将 double 转换为 int，小数部分被截断 (结果为 9)
    ```

## 3. 修饰符 (Modifiers)
- 修饰符用于修改类、方法、变量等的定义和行为。分为**访问控制修饰符**和**非访问控制修饰符**。
- 通常访问控制修饰符写在非访问控制修饰符之前。
### 3.1 访问控制修饰符 (控制可见性)

| 修饰符      | 同一个类 | 同一个包 | 不同包子类 | 不同包非子类 | 使用对象                  |
| :---------- | :------- | :------- | :--------- | :----------- | :------------------------ |
| `public`    | Yes      | Yes      | Yes        | Yes          | 类, 接口, 变量, 方法     |
| `protected` | Yes      | Yes      | Yes        | No           | 变量, 方法 (不能修饰外部类) |
| `(default)` | Yes      | Yes      | No         | No           | 类, 接口, 变量, 方法     |
| `private`   | Yes      | No       | No         | No           | 变量, 方法 (不能修饰外部类) |
*   **`(default)`:** 不写任何访问修饰符时的默认状态。

### 3.2 非访问控制修饰符

*   **`static`:**
    *   修饰变量/方法(类变量/静态变量/类方法/静态方法): 变量属于类本身，所有对象共享同一个变量。静态方法不能直接访问非静态成员（变量或方法）。可以通过 `类名.变量名` 访问。
    *   不能修饰局部变量。
*   **`final`:** 相当于C中的const
    *   修饰变量: 变量的值一旦初始化后**不能被重新赋值** (常量)。
    *   修饰方法: 方法**不能被子类重写 (Override)**，但可以被继承。
    *   修饰类: 类**不能被继承**。
*   **`abstract`:**
    *   修饰类 (抽象类): 类不能被实例化 (不能 `new` 对象)。主要用于被继承，提供通用模板。
    *   修饰方法 (抽象方法): 包含抽象方法的类**必须**声明为抽象类，否则会出现编译错误。
    * 子类继承抽象类后，必须实现所有抽象方法，除非子类也是抽象类。
*   **`synchronized`:** (多线程相关)
    *   用于控制对共享资源的并发访问。
    *   修饰方法或代码块，确保同一时间只有一个线程能执行该方法或代码块。
    *   (需要深入学习多线程知识)
*   **`transient`:** (序列化相关)
    *   修饰成员变量。在对象序列化（将对象状态写入字节流）时，被 `transient` 修饰的变量的值**不会**被包含在序列化的数据中。
    *   (需要学习 Java I/O 和序列化知识)
*   **`volatile`:** (多线程相关)
    *   修饰成员变量。保证了不同线程对该变量操作的**可见性**，即一个线程修改了变量的值，其他线程能够立即看到这个修改。
    *   确保每次读取变量都从主内存中读取，每次修改变量都立即写回主内存。
    *   (需要深入学习 Java 内存模型和并发编程)

## 5. 方法参数传递机制：值传递
Java 中**只有值传递 (Pass by Value)**，但对于对象，传递的是**引用的拷贝**，所以看起来像“引用传递”。但**不能改变对象的引用本身**，只能修改对象的内容。

### 5.1 传递基本数据类型
*   **传递基本数据类型 (如 `int`, `float`, `boolean`):**
    *   方法接收的是**原始值的副本**。
    *   方法内部对参数副本的任何修改，**不会**影响方法外部的原始变量。

    ```java
    public class PrimitivePassing {
        public static void modifyValue(int value) {
            System.out.println("方法内，修改前: value = " + value); // 输出 10
            value = 100; // 修改的是 value 的副本
            System.out.println("方法内，修改后: value = " + value); // 输出 100
        }

        public static void main(String[] args) {
            int originalValue = 10;
            System.out.println("方法调用前: originalValue = " + originalValue); // 输出 10
            modifyValue(originalValue);
            System.out.println("方法调用后: originalValue = " + originalValue); // 仍然输出 10
        }
    }
    ```

### 5.3 传递引用数据类型
*   **传递引用数据类型 (如 对象, 数组):**
    *   方法接收的是**原始引用（内存地址）的副本**。
    *   这个副本引用和原始引用**指向堆内存中的同一个对象**。
    *   因此，在方法内部通过**参数引用**（副本引用）去修改**对象的内容**（例如，修改对象的属性或数组的元素），这个修改会**反映**在原始对象上，因为它们指向同一个对象。
    * 如果在方法内部将**参数引用**重新赋值，使其指向一个**新的对象**，这**不会**影响方法外部的原始引用，原始引用仍然指向原来的对象。


    ```java
    class Data {
        int value;
        Data(int value) { this.value = value; }
    }

    public class ReferencePassing {
        // 通过引用修改对象内容
        public static void modifyObjectContent(Data dataRef) {
            System.out.println("方法内，修改内容前: dataRef.value = " + dataRef.value); // 输出 10
            dataRef.value = 100; // 修改了堆中同一个对象的内容
            System.out.println("方法内，修改内容后: dataRef.value = " + dataRef.value); // 输出 100
        }

        // 尝试改变引用指向
        public static void changeReference(Data dataRef) {
            System.out.println("方法内，改变指向前: dataRef.value = " + dataRef.value); // 输出 100 (或 10，取决于调用顺序)
            dataRef = new Data(200); // 让参数 dataRef 这个引用副本指向了新对象
            System.out.println("方法内，改变指向后: dataRef.value = " + dataRef.value); // 输出 200
        }

        public static void main(String[] args) {
            Data originalData = new Data(10);
            System.out.println("方法调用前: originalData.value = " + originalData.value); // 输出 10

            modifyObjectContent(originalData);
            System.out.println("modifyObjectContent 调用后: originalData.value = " + originalData.value); // 输出 100 (原始对象内容被修改)

            changeReference(originalData);
            System.out.println("changeReference 调用后: originalData.value = " + originalData.value); // 仍然输出 100 (原始引用未改变指向)
        }
    }
    ```

## 6. Java 中的变量类型
*   **局部变量 (Local Variables):**
    *   **声明位置:** 在方法、构造器或代码块 (`{}`) 内部声明。
    *   **生命周期:** 从声明处开始，到其所在的代码块执行完毕时结束。
    *   **存储位置:** Java 虚拟机栈 (JVM Stack) 的栈帧中。
    *   **初始化:** **必须**在使用前显式初始化，没有默认值。
    *   **垃圾回收:** 当方法执行完毕，对应的栈帧出栈，局部变量随之销毁，其占用的栈内存被回收。
*   **成员变量 (Member Variables) / 实例变量 (Instance Variables):**
    *   **声明位置:** 在类中，但在任何方法、构造器或代码块之外。
    *   **作用域:** 在整个类中都可见（访问级别取决于访问修饰符）。可以通过 `this` 关键字访问。
    *   **生命周期:** 随着对象的创建而创建，随着对象的销毁而被垃圾回收器回收。
    *   **存储位置:** 堆内存 (Heap) 中，作为对象的一部分。
    *   **初始化:** 有默认值（数值类型为 0/0.0，`boolean` 为 `false`，`char` 为 `\u0000`，引用类型为 `null`）。也可以在声明时或构造器中显式初始化。
    *   **访问:** 必须通过类的实例（对象）来访问 (`objectName.variableName`)。
*   **类变量 (Class Variables) / 静态变量 (Static Variables):**
    *   **声明位置:** 在类中，使用 `static` 关键字修饰。
    *   **作用域:** 在整个类中都可见，甚至在没有创建对象实例时也可以访问。
    *   **生命周期:** 随着类的加载而创建，随着程序的结束而销毁。生命周期比对象实例长。
    *   **存储位置:** 堆内存的方法区 (Method Area) 或元空间 (Metaspace) 中（取决于 JVM 实现）。
    *   **初始化:** 有默认值（同成员变量）。在类加载时初始化。
    *   **访问:** 可以通过类名直接访问 (`ClassName.variableName`)，也可以通过对象实例访问 (`objectName.variableName`，但不推荐）。
    *   **共享:** 该类的所有对象共享**同一份**静态变量的拷贝。   
*   **参数变量 (Parameters):**值传递的副本
    *   **声明位置:** 在方法或构造器的参数列表 `()` 中声明。
    *   **作用域:** 仅限于其所在的方法或构造器内部。
    *   **生命周期:** 方法或构造器调用时创建，执行完毕时销毁。
    *   **作用:** 接收调用者传入的数据。其行为遵循**值传递**机制。

## 函数
### 方法重载（Method overloading ）

*   **定义:** 在**同一个类**中，允许存在一个以上的同名方法，只要它们的**参数列表不同**即可。
*   **目的:** 提高代码的可读性和复用性，可以用相同的方法名处理不同类型或数量的数据。
*   **判断标准 (满足以下任一即可构成重载):**
    1.  **参数个数**不同。
    2.  **参数类型**不同。
    3.  **参数类型的顺序**不同 (如果类型不同)。
*   **与返回值无关:** 方法的**返回值类型不能**作为区分重载方法的标准。不能只有返回值类型不同

## 9. 代码规范与 Javadoc
### 9.1 编码规范
- 用阿里开发手册
*   **核心命名规范 :**
    *   **类名:** 大驼峰 (UpperCamelCase)
    *   **方法名/变量名:** 小驼峰 (lowerCamelCase)
    *   **包名:** 全小写
    *   **常量名:** 全大写，下划线分隔 (UPPER_SNAKE_CASE)
	*   可以由字母、数字、下划线 (`_`)、美元符号 (`$`) 组成。
	*   **不能**以数字开头。

### 9.2 Javadoc 文档注释
*   **作用:** 用于为类、接口、方法、成员变量等生成 API 文档 (通常是 HTML 格式)。是 Java 源码的一部分，也是重要的项目文档。
-   **格式:** 以 `/**` 开始，以 `*/` 结束。中间每行通常以 `*` 开头。
#### 注释
1.  **单行注释:** `//` 用于行内或简短说明。
2.  **多行注释:** `/* ... */` 用于注释掉一段代码或较长的说明 (不用于 Javadoc)。

*   **常用 Javadoc 标签:**
    *   `@param parameterName description`: 描述方法参数。
    *   `@return description`: 描述方法返回值。
    *   `@throws exceptionType description` / `@exception exceptionType description`: 描述方法可能抛出的异常。
    *   `@author authorName`: 作者名。
    *   `@version versionInfo`: 版本号。
    *   `@since jdkVersion`: 指明从哪个 JDK 版本开始引入。
    *   `@see reference`: 引用其他相关类或方法。
    *   `@deprecated description`: 标记为不推荐使用的方法或类，并说明原因或替代方案。

*   **规范注释示例:**
    1.  **类注释:**
        ```java
        /**
         * 表示一个简单的计算器类，提供基本的加法运算。
         *
         * @author Your Name
         * @version 1.0
         * @since JDK 1.8
         */
        public class Calculator {
            // ... 类内容 ...
        }
        ```

    2.  **方法注释:** (在 IDEA 等 IDE 中输入 `/**` 后按 Enter 可自动生成模板)
        ```java
        /**
         * 计算两个整数的和。
         *
         * @param numberA 第一个加数
         * @param numberB 第二个加数
         * @return 两个整数的和
         * @throws IllegalArgumentException 如果输入参数无效 (示例)
         */
        public int sum(int numberA, int numberB) {
            // ... 方法实现 ...
            return numberA + numberB;
        }
        ```

### 处理多个 Java 文件

假设项目包含 `Employee.java` (定义 Employee 类) 和 `EmployeeTest.java` (包含 `main` 方法，使用 Employee 类)。

1.  **编译:** 需要同时编译所有相关的 `.java` 文件。
    ```bash
    # 确保 Employee.java 和 EmployeeTest.java 在同一目录
    javac Employee.java EmployeeTest.java
    ```
    或者使用通配符：
    ```bash
    javac *.java
    ```
    这将生成 `Employee.class` 和 `EmployeeTest.class`。
2.  **运行:** 运行包含 `main` 方法的那个类。
    ```bash
    java EmployeeTest
    ```
