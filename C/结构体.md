 - 一种数据类型
 - 我们想要定义的类型（一般是全局的）


创建了一个结构体，类型名叫struct Date。

```C
typedef struct Date{
	int day；
	int month；
	int year；
}Date;

Date today = {12, 2, 2024};

```
上例是改类型名；
结构体中的是成员。

## 访问结构体成员
### 通过 . 访问成员
```C
printf("Today's date is :%d-%d-%d\n", today.year, today.month, today.day);
```

### 通过指针访问

```C
Date* date_ptr = &today;

printf("Today's date is :%d-%d-%d\n", date_ptr->year, date_ptr->month, date_ptr->day);
```

## 枚举(Enumeration)（一种数据结构）

```C
typedef enum {
	MONDAY,  //从0开始
	TUESDAY,
	WEDNESDAY,
	THURSDAY,
	FRIDAY,
	SATURDAY,
	SUNDAY
}Weekday;

const char* get_weekday_name(Weekday day);

int main(void) {
	// 枚举 Enumeration
	Weekday day = FRIDAY;   //可写可不写
	printf("%d\n", FRIDAY);
	//printf("%d\n", day);

	printf("%s", get_weekday_name(day));

	return 0;
}

const char* get_weekday_name(Weekday day) {
	switch (day) 
	{
	case MONDAY: return "MONDAY";
	case TUESDAY: return "TUESDAY";
	case WEDNESDAY: return "WEDNESDAY";
	case THURSDAY: return "THURSDAY";
	case FRIDAY: return "FRIDAY";
	case SATURDAY: return "SATURDAY";
	case SUNDAY: return "SUNDAY";
	}
}
```

如果要输出字符串，还是要用到函数，不能直接输出。

## 联合Union（一种数据类型）（共用体）

它允许在相同的内存位置存储不同的数据类型。
联合体的所有成员共享一块内存空间，大小等于其最大成员的大小。
意味着在任一时刻，联合体只能存储一个成员的值

一个变量可能存储多种类型的数据，但是在一个给定时刻里，只是用其中一种数据类型，可以节省内存。

```C
typedef union {
	int int_value;
	float float_value;
	char* string_value;
}Data;

typedef enum {
	INT,
	FLOAT,
	STRING
}DataType;

typedef struct {
	DataType type;
	Data data;
}TypeData;

void print_data(TypeData* typed_data) {
	switch (typed_data->type)
	{
	case INT: printf("Integer: %d\n", typed_data->data.int_value);
		break;
	case FLOAT: printf("Float: %f\n", typed_data->data.float_value); 
		break;
	case STRING: printf("String: %s\n", typed_data->data.string_value); 
		break;
	}
}
int main(void) {

	TypeData data1 = { INT, {.int_value = 10} };
	TypeData data2 = { FLOAT, {.float_value = 3.14} };
	TypeData data3 = { FLOAT, {.string_value = "Hello, Union!"} };

	print_data(&data1);
	print_data(&data2);
	print_data(&data3);

	return 0;
}
```
