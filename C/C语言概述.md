## 大致介绍
### # include指令和头文件
 ~~~C
 # include <stdio.h>
 ~~~
 这行代码是一条预处理器指令，在编译前进行的准备工作。
 stdio.h文件是头文件

### main()函数
 标准格式：int main(void)（函数名）

### 注释
/* 一个简单的程序 * /
或者：//这种注释只能写一行

### 花括号，函数体和块
所有C函数都使用花括号标记函数体的开始和结束，
花括号还可用于把函数中的多条语句合并为一个单元或块


### 标识符规则：
- 小写字母，大写字母，数字和下划线（_ )
- 名称的第一个字符必须是字母或下划线
- 区分大小写
注：声明最好放一块儿。
