## 自定义日志函数
主要成分：
- log_message
- 日志级别(level)
	- LOG_INFO
	- LOG_WARNING
	- LOG_ERROR
- 格式化字符串
- 自动添加时间戳



buffer要共享，所以设置静态

```C
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <stdarg.h>
//自定义函数

typedef enum {
	LOG_INFO,
	LOG_WARNING,
	LOG_ERROR,
} LogLevel;

const char* get_current_time();
void log_message(LogLevel level, const char* format, ...);

int main(void) {
	log_message(LOG_INFO, "This is an information message with a number: %d", 42);
	log_message(LOG_WARNING, "This is an warning for users: %d", "ABC");
	log_message(LOG_ERROR, "This is an error message related to file: %s", "example.txt");
}

const char* get_current_time() {
	static char buffer[20];
	time_t now = time(NULL);//获取系统时间，秒数
	struct tm tm_info;//使用tm类型
	localtime_s(&tm_info, &now);//使用tm_info的值来填充tm结构，后面是用来存储时间的指针
	strftime(buffer, 20, "%Y-%m-%d %H:%M:%S", &tm_info);//将时间存入字符串
	
	return buffer;
}

void log_message(LogLevel level, const char* format, ...) {
	const char* level_str;
	switch (level)
	{
	case LOG_INFO:level_str = "INFO"; break;
	case LOG_WARNING:level_str = "WARNING"; break;
	case LOG_ERROR:level_str = "ERROR"; break;
	default: level_str = "UNKNOWN"; break;
	}

	printf("[%s] [%s]", get_current_time(), level_str);

	va_list args;
	va_start(args, format);
	vprintf(format, args);//使用参数列表的printf
	va_end(args);

	printf("\n");
}
```

## 关于exit(0),exit(1),return

![[Pasted image 20240426175038.png]]

1. return返回函数值，是关键字；  exit 是一个函数。

  2. return是语言级别的，它表示了调用堆栈的返回；而exit是系统调用级别的，它表示了一个进程的结束。  
  3. return是函数的退出(返回)；exit是进程的退出。

  4. return是C语言提供的，exit是操作系统提供的（或者函数库中给出的）。

  5. return用于结束一个函数的执行，将函数的执行信息传出个其他调用函数使用；exit函数是退出应用程序，删除进程使用的内存空间，并将应用程序的一个状态返回给OS，这个状态标识了应用程序的一些运行信息，这个信息和机器和操作系统有关，一般是 0 为正常退出， 非0 为非正常退出。

  6. 非主函数中调用return和exit效果很明显，但是在main函数中调用return和exit的现象就很模糊，多数情况下现象都是一致的。

exit（0）与exit（1）对你的程序来说，没有区别。对使用你的程序的人或者程序来说，区别可就大了。  
一般来说，exit 0 可以告知你的程序的使用者：你的程序是正常结束的。如果 exit 非 0 值，那么你的程序的使用者通常会认为你的程序产生了一个错误。  
  
以 shell 为例，在 shell 中调用完你的程序之后，用 echo $? 命令就可以看到你的程序的 exit 值。在 shell 脚本中，通常会根据上一个命令的 $? 值来进行一些流程控制。


## assert 断言

- 什么是断言？

如果假设为真，通过；如果不为真，不通过，终止。

需要引入头文件<assert.h>，

输出的是stderr类型，标准的错误输出。

```C
#include <assert.h>

int a = 5;
assert(a == 5);

a = 3;

assert(a == 5);//断言失败，程序终止

puts("Hello");//这里的Hello不会输出，程序会报错
```

- 使用场景
用于开发的过程中捕获错误
发布（release）之后，所有的断言全都不奏效
不适用于处理运行时候的错误情况

可变参，函数在开始之前是什么，结束之前是社么
逻辑错误

快速定位错误的位置

- 注意
软件发布的时候，要把断言注释掉或者删掉。

- 禁用断言的方式
`#define NDEBUG`
release的时候使用禁用断言
