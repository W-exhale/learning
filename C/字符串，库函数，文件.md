## 存储
可以用数组或者指针的方式存储

用数组定义字符串时一般不用显式的方式。
- 隐藏的`\0`

用指针存储字符串是存储的第一个的地址。

- 数组定义的字符串可以修改，指针的不行
- 用const修饰的字符串修改会报错（最好加一下）
- 指针不会报错

### strlen()

算字符串长度，不算`\0`。

消除警告（觉得不安全，如果没初始化会报错）的赋值方式。




### strcat()

拼接字符串，
```C
int main()
{
	char dest[50] = {0};
	 
	strcpy_s(dest, sizeof(dest), "Hello");

	const char* src = ", World!\n";

	size_t dest_size = sizeof(dest) - strlen(dest) - 1;

	strcat_s(dest, dest_size, src);//中间的是还剩的容量
	
	printf("%s", dest);

	return 0;
}
```


### sprintf()（C11后加_s）

专属于字符串的格式化输出。
常规的printf（）不会处理缓冲区溢出的情况，sprintf（）可以处理这个问题。



sprint（）的作用是把后面所有的数代入后，把后面全部变成一个字符串放入buffer。返回值是判断是否溢出。

捕获异常：188.

### 流（stream）

#### 文件流

磁盘
用与读取与写入在磁盘上的文件

w,r+,w+...各种模式
r：只读
w：覆盖写，用于销毁文件。
a：追加（常用）

带“+”都是打开可读写文件，不带的是打开特定的文件。
##### fopen_s()打开文件
fopen(),创建一个流

![[Pasted image 20240319072914.png]]


- fgets()一行一行读
- fgetc()一个字一个字的读（不用放到缓冲区）

只读一遍，第一次读指针已经到了文件末尾。可以用rewind(file_stream);把指针放回开头。第一次读完后要把缓冲区清理一下，memset(buffer, 0, sizeof(buffer));

#### 标准I/O流

- stdin：默认连接到键盘，用于程序输入
- stdout：默认连接到控制台（cmd）或屏幕，用于程序输出
- stderr：默认连接到控制台或屏幕，专门输出错误信息和警告，使得其能够被区分开来或者是重定向到不同的目的地。
可以用在fprintf()等的第一个参数
#### 管道流
用于进程之间的通信（IPC），允许一个进程的输出成为另一个进程的输入popen()

#### 内存流

允许你将流与内存缓冲区关联，使得你可以向内存中读写数据，就像操作文件一样。POSIX->fmemopen

#### 网络流
套接字（Sockets）

A发到总部，总部发到B，B作用之后再返回总部，总部发到A

#### 设备流
