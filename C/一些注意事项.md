## 类型转换（Type Conversation）


### 隐式转换
`bigNum = smallNum;`

### 显式转换（强制转换）[好的编程习惯]
`smallNum = bigNum;`
 
#### 大范围到小范围
`int32_t mediumNum = 123123123;`
`int16_t smallNum = (int16_t)mediumNum;`
使用强制转换有利于找到类型转换时的错误
比如，转错了。
#### 小范围到大范围
`int16_t smallNum = 32767;`
`uint32_t bigNum = (uint32_t)smallNum;`


## 固定整数类型转换
<inttypes.h>这个头文件里有<stdint.h>，主要是一些特殊的值。下面那些都是在<stdint.h>头文件中有的。

### 固定宽度整数类型
```C
int8_t myInt8 = INT8_MAX; 
printf("int8_t: %hhd\n", myInt32);
printf("int8_t: %" PRId8 "\n", myInt32);
```
不能超过，超过了就溢出了。
标准整数类型 -> 固定宽度整数类型
固定的位数，不可以越界，适用于需要精确数据大小的场景。（网络的传输...）
### int_least8_t number;
定义的时候，保证至少有特定的位数

int_leastN_t number;
至少有N位，可能更多，适用于需要保证最小存储容量的可移植代码。
### int_fast8_t
特效，用最快的速度（不考虑节省空间）

int_fastN_t 
至少有N位，但是选择运算最快的类型（主打一个速度），适用于需要性能敏感的场景。（游戏渲染）
