函数是指完成特定任务的独立程序代码单元。

可以将程序看成是根据传入信息（输入）及其生成的值或响应的动作（输出）来定义的黑盒。
## 基本介绍
### 函数参数
可以使用不同形式的数据类型作为函数参数
### 声明带形式参数函数的原型
使用ANSI C形式声明
void show_n_char(char ch, int num);
函数原型用逗号分隔参数，在原型中可以不用实际创建变量
~~~
void show_n_char(char, int)
~~~

### void含义

```
void greet();
void greet(void);
```
如果括号中没有void， 可以传递任何参数。
但是如果有，不能传递任何参数，调用函数的时候，括号里不能放参数。

### 作用域
不在作用域内使用变量会出现的问题：内存泄漏，访问已经被销毁的变量（悬挂引用），过度消耗资源。
大括号括起来的就是一个作用域，可以没有for，函数之类的。！！小作用域出了大括号里面的变量啥的就丢了。
小作用域里的东西不应该影响到外面的程序。
局部变量要初始化，不然会占用栈的位置，如果初始化，每次该函数调用结束内存都会销毁。

全局变量不初始化，只定义，就为0；
如果是指针，就默认为NULL； 
- 程序范围的可见性
- 静态存储期
线程安全问题：在多线程环境中，为加锁的全局变量可能会导致数据竞争和不一致。

- 静态局部变量
`static int counter = 0;`
static贯穿整个程序，作用域还是有范围。静态局部变量，跨函数调用，保持状态和计数（会变）
加了这个关键字的全局变量，不可以被extern的使用

- extern 关键字
`extern int number;`
加了这个关键字后可以用其他文件中的全局变量。（关键字起一个找东西的作用）

- 寄存器变量（）内存非常小
声明寄存器变量，建议编译器尽可能将counter放在寄存器中。
`register int counter;`
放在寄存器里，用完就扔，不在内存里，不能使用&counter获得地址

链接性（Linkage）
可以用其他文件的函数（外部链接）
用本函数的函数（内部链接）
局部变量，无链接
块作用域（Block Scope）：大括号里的

### 使用return 从函数中返回值
- 驱动程序：被设计用于测试函数的程序
如果函数成功通过测试，就可以安装在一个更重要的程序中使用

~~~C
#include<stdio.h>
int imin(int, int);

int main(void)
{
	int evil1, evil2;

	printf("Enter a pair of integers (q to quit):\n");
	while (scanf("%d %d", &evil1, &evil2) == 2)
	{
		printf("The lesser of %d and %d is %d.\n", evil1, evil2, imin(evil1, evil2));
		printf("Enter a pair of integers(q to quit)");
	}
	printf("Bye.\n");

	return 0;
}

int imin(int n, int m)
{
	int min;

	if (n < m)
		min = n;
	else
		min = m;

	return min;
}
~~~
函数的返回值类型由函数头中第一个数决定
- 只在函数末尾使用一次return 语句比较好，这样更方便浏览程序的人理解函数的控制流。
- 如果没有返回值，即，void，return后可以没有值，也可以没有return

### 函数类型
- 函数类型指的是返回值类型，不是函数参数的类型
- 把函数定义在第一次调用前增加了程序的阅读难度，通常是提前声明函数，把函数信息告知编译器。

## ANSI C 函数原型
主调函数把函数的参数存储在被为栈的临时存储区，被调函数从栈中读取这些参数。
主调函数根据函数调用中的实际参数决定传递的类型，被调函数根据它的形式参数读取值。
第二次使用imax（）函数时，传递的是float类型的值。这次把两个double类型的值放在栈中。在该系统中，两个double类型的值就是两个64位的值，所以128位的数据被放在栈中，当imax从栈中读取两个int类型的值时，它从栈中读取前64位（该系统的int类型变量占32位）

### ANSI C 的解决方案
ANSI C标准要求在函数声明时还要声明变量的类型，即用函数原型来声明函数的返回类型，参数的数量和每个参数的类型。
这里的变量名时假名，不必与函数定义的形参一致。
如果两个参数都是数字，但类型不匹配，编译器会把实际参数的类型转换成形式参数类型。

### 无参数和未指定参数
假设有一个函数原型：
void print_name();
- 不支持ANSI C的编译器：假定用户没有用函数原型来声明函数，它不会检查参数。（为了表明函数确实没有参数，在该种情况下，最好写成：void print_name(void);)
- 支持的：将其解释为print_name()不接受任何参数。所以在调用函数时，编译器会检查以确保没有使用参数。
例如，printf（）第一个参数时字符串，其余参数的类型和数量都不固定，对于这种情况，ANSI C允许使用部分原型。
int printf(const char*,...);
这种原型表明，第一个参数是一个字符串，可能还有其他未指定的参数。
C库通过stdarg.h头文件提供了一个定义这类（形参数量不固定的）函数的标准方法。

### 函数原型的优点
让编译器捕获在使用函数时可能出现的许多错误或疏漏。

## 递归
解释：函数调用自己的过程。

- 上述中的程序：输入1，n小于4，up_and_down()（第一级）调用实际参数为2的up函数，2小于4，第二级再调用第三级。。。
- 形成了一个函数链，fun1（）调用fun2（），fun2（）调用fun3（），fun3（）调用fun4（）.当fun4结束时，控制传回fun3（）（fun3是fun4的主调函数），fun3结束传回fun2（），fun2（）结束，传回fun1（）。

### 递归的基本原理
- 每级函数调用有自己的变量。也就是说，第一级的n和第二级的n不同。所以程序创建了四个单独变量，每个变量名都是n，
- 每次函数调用都会返回一次，执行完毕后，只能返回上一级，不能跳级回到main的一级调用。
- 递归函数位于调用函数之前的语句，均按被调函数的顺序执行。
- 位于调用函数之后的语句，均按被调函数相反的顺序执行。
- 每级递归都有自己的变量，但是没有拷贝函数的代码，
- 要包含让递归停止的条件

### 尾递归
解释：把递归调用至于函数的末尾，即正好在return语句之前，在返回值后加一个累加器。（和循环很像）
尾递归的性能取决于编译器（MS VC，gcc）
注：可以用循环就不用递归。
- 每次递归都会创建一组变量，所以递归使用的内存更多
- 每次递归调用都会把创建的一组新变量放在栈中
- 存在栈溢出时使用递归

### 递归和倒序运算
递归在处理倒序时非常方便，例如，编写一个函数，打印一个整数的二进制数。
### 斐波那契函数
~~~
unsigned long Fibonacci(unsigned n)
{
	if(n>2)
		return Fibonacci(n - 1) + Fibonacci(n - 2);
	else
		return 1;
}
~~~

## 编译多源代码文件的程序
使用多个函数最简单的方法是把他们都放在同一个文件中，然后像编译只有一个函数的文件那样编译该文件即可。

### UNIX
假定在UNIX系统中安装了UNIX C编译器cc（gcc或clang）
### 使用头文件
- 如果把main（）函数放在第一个文件中，
- 把函数定义放在第二个文件‘
- 把函数原型放在头文件中。
 C标准库就是如此，例如，I/O函数原型放在stdio.h中，数学函数原型放在math.h中。
- C预处理器的#define也可以放进头文件，然后使用#include指令包含即可
- 把函数原型和已定义的字符常量放在头文件中是一个良好的编程习惯
