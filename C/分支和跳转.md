## 多层嵌套的if语句
应用：给定一个整数，显示所有能整除它的约数。如果没有约数，则报告该数是一个素数。（用开平方的方式找素数）
设计程序：
1. 使用一个循环让让用户连续输入待测试的数：
 ~~~
	提示用户输入数字
	当scanf（）返回值为1
		分析该数并报告结果
		提示用户继续输入
~~~
2. 设计如何找出约数
	分析：用循环检查2-num之间所有数字，测试它们是能被num整除，但是这个方法有点浪费时间，我们可以改进一下，成功处理一个数可以知道两个约数，例如144，其实在得到12和12这对约数后，所有约数都有了，大大节省了循环时间。
	综上，在找约数时，只需要测试到num的平方根就行。
~~~
for(div = 2;(div *div) <= num;div ++)
{
	if(num % div == 0){
		if(div *div != num)
			printf("%d is divisible by %d and %d.\n", num, div, num / div);
		else
			printf("%d is divisible by %d.\n", num, div)；
	}
}
~~~
3. 如何知道一个数是素数
如果num是素数就不会进入循环，为解决这个问题可以在外层循环把一个变量设置为某个值（如：1），然后在if语句中把他设置为0；检查是否为1；如果是说明没有进入if语句，就没有约数，是素数

## 一个统计单词（数量）的程序
还可以计算字符数和行数
- 首先，该程序要逐个字符读取输入，知道何时停止读取。然后，该程序能识别并计算这些内容：字符，行数和单词。
~~~
读取一个字符
当有更多输入时
	递增字符计数
	如果读完一行，递增行数计数
	如果读完一个单词，递增单词计数
	读取下一个字符
~~~
输入循环的模型：
while（（ch = getchar（））！=STOP）{
...
}
这里的STOP表示能标识输入末尾的某个值，之前我们用过换行符，或句点标记输入的末尾，但是对于一个统计单词的程序，它们都不合适。（暂时用文本中不常用的字符（“|”）作为输入的末尾标记），第八章会介绍更好的方法。
统计行数：
可以通过统计换行符的个数来计数，但是要注意STOP位于字符中间的情况，看这时是否递增行数？，我们可以作为特殊行计数，即没有换行符的一行字符。可以通过记录之前读取的字符识别这种情况，如果读取时发现STOP的上一个字符不是换行符，那么他就是特殊行。
识别单词：
1. 定义什么是该程序识别的单词，（不含空白的字符序列），程序读取的第一个非空白序列就是一个单词的开始，检测空白的表达式有一串（空格，换行，制表符，等等），可以用ctype.h头文件中的isspace（）函数，如果该字符为空白字符返回真。
2. 要查找某个字符（空白字符），可以在程序读入单词的首字符是把一个标记（名为inword）设置为1，也可以在此时递增单词计数。然后，只要inword为1，（或ture），后续的空白字符都不记为单词的开始，下一个空白字符必须重置标记为0（或false）之后程序读取下一个单词
写成伪代码：
~~~
如果c不是空白字符，且inword为假
	设置inword为真，并给单词计数
如果c是空白字符，且inword为真
	设置inword为假
~~~
inword可以用布尔类型，也可以用1或0表示（int）

## 循环辅助：continue 和 break
### continue 语句
跳过本次迭代的剩余部分，并开始下一轮迭代，如果在嵌套循环内，只影响一层。

- 应用：用于筛选
### break 语句
跳出循环，在嵌套循环内只影响一层。
